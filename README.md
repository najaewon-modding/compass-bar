# Compass Bar

Minecraft의 기본 Player List를 화면 상단의 방향 기반 Compass HUD로 대체하는 NeoForge 모드입니다.

현재 바라보는 방향과 같은 차원에 있는 다른 플레이어의 방향을 한눈에 확인할 수 있으며, 서버가 플레이어별 마커 색상을 영구적으로 관리합니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |
| Java | `25` |
| 멀티플레이 | 서버/클라이언트 지원 |

## 주요 기능

- 화면 상단에 Compass Bar 표시
- 게임 접속 시 Compass HUD 기본 활성화
- 카메라 방향에 따라 방위 표시가 실시간으로 이동
- 기본 Player List 키로 Compass HUD 켜기/끄기
- 같은 차원에 있는 다른 플레이어의 방향을 마커로 표시
- 거리에 따라 플레이어 마커 크기 변경
- 서버가 UUID 기준으로 플레이어마다 고유한 마커 색상 배정
- 같은 월드에서는 재접속 및 서버 재시작 후에도 마커 색상 유지
- 화면 오른쪽 중앙에 현재 플레이어와 자신의 마커 색상 표시
- Player Locator Bar 대신 Experience Bar를 항상 표시
- 모드가 없는 클라이언트도 Compass Bar가 설치된 서버에 정상 접속 가능

### 플레이어 마커

다른 플레이어는 Compass Bar 위에 다이아몬드 형태의 마커로 표시됩니다.

| 거리 | 마커 크기 |
| --- | --- |
| 64블록 이하 | 5 × 5 |
| 64~256블록 | 4 × 4 |
| 256블록 초과 | 3 × 3 |

현재는 **같은 차원에 있는 플레이어만** Compass Bar에 표시됩니다.

### 영구 마커 색상

서버는 각 플레이어의 UUID를 기준으로 마커 색상을 한 번 배정하고 월드 SavedData에 저장합니다. 따라서 같은 월드에서는 플레이어가 재접속하거나 서버가 재시작되어도 기존 색상이 유지됩니다.

새 플레이어에게는 넓은 색상 범위에서 후보를 생성한 뒤 기존 색상과의 OKLab 최소 거리가 최대가 되는 색을 우선 배정합니다. 동일한 RGB 값은 다시 사용하지 않으며, HUD에서 식별하기 어려울 정도로 지나치게 어둡거나 옅은 색은 제외합니다.

### Experience Bar 유지

Compass Bar를 사용하는 동안 vanilla Player Locator Bar 대신 기존 Experience Bar를 항상 표시합니다. 플레이어 위치 정보는 Compass Bar가 담당하고 경험치 표시는 원래 위치에 유지됩니다.

## 조작

기본 Minecraft의 **Player List** 키를 그대로 사용합니다.

기본 키:

```text
Tab
```

- 접속 시 Compass HUD는 기본적으로 켜져 있습니다.
- Player List 키를 한 번 누르면 꺼지고, 다시 누르면 켜집니다.
- Minecraft Controls에서 Player List 키를 변경하면 Compass Bar도 변경된 키를 그대로 사용합니다.

## 설치

### 서버

Compass Bar JAR 파일을 서버의 `mods` 폴더에 넣습니다.

### 클라이언트

Compass HUD를 사용하려는 플레이어는 동일한 JAR 파일을 클라이언트의 `mods` 폴더에 넣습니다.

## 멀티플레이 동작

서버는 플레이어 위치와 영구 마커 색상 정보를 Compass Bar를 지원하는 클라이언트에 전달하고, 클라이언트는 그 정보를 이용해 HUD를 렌더링합니다.

| 서버 | 클라이언트 | 동작 |
| --- | --- | --- |
| Compass Bar 설치 | Compass Bar 설치 | 모든 기능 사용 |
| Compass Bar 설치 | 모드 없음 | Vanilla UI로 정상 접속 |

클라이언트에 Compass Bar가 설치되어 있지 않으면 서버는 해당 클라이언트에 전용 패킷을 보내지 않습니다. 따라서 서버에 모드를 설치하더라도 모든 플레이어에게 클라이언트 모드 설치를 강제하지 않습니다.

## 기술 정보

- 서버 측 플레이어 색상은 월드 SavedData에 저장됩니다.
- 마커 색상은 UUID를 기준으로 유지됩니다.
- 플레이어 위치 표시는 같은 차원으로 제한됩니다.
- HUD 렌더링은 클라이언트에서 처리합니다.
